How do I export the log?

In your Moodle course go to Reports → Logs, leave "All participants" / "All days", set the Download format to JSON, and download. Then drop that file above.

Course

The engagement score is class-relative — it ranks effort within this class, not against an absolute standard; small classes make the curve noisier. Moodle logs contain no due dates, so a "missing submission" means none was recorded at all (not lateness). Roles are auto-detected — use Manage roles to correct any. Times are shown as recorded in the export.
